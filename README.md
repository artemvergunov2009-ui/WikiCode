# WikiCode — Справочник для начинающего программиста

## О проекте
**WikiCode**[cite: 1] — это учебный веб-сайт, который представляет собой удобный справочник по основам программирования. Мы собрали в одном месте базовую теорию, шпаргалки и разбор основных тем, чтобы новичкам было проще учиться и быстро находить нужную информацию.

## Для чего нужен сайт
Когда только начинаешь изучать программирование, легко запутаться в большом количестве информации из разных источников. Наш справочник помогает:
* Быстро вспомнить синтаксис и базовые конструкции кода.
* Повторить основные темы перед практикой или парами.
* Изучать теорию в простом и понятном формате без лишней «воды».

## Что уже реализовано
* Веб-интерфейс с удобной навигацией по разделам.
* База обучающих материалов и статей по базовым темам.
* Локальный сервер на Python для запуска сайта и работы с данными.

## Стек технологий
* **Python** — серверная часть (`main.py`)[cite: 1].
* **HTML5 и CSS3** — верстка страниц и оформление (`index.html`, `style.css`)[cite: 1].
* **Базовая клиентская логика** — отображение материалов на странице.

## Структура проекта
* `main.py` — главный файл для запуска сервера[cite: 1].
* `public/` — папка с шаблоном страницы и стилями[cite: 1].
* `data/` — папка с базой статей и учебных материалов[cite: 1].
* `requirements.txt` — список используемых библиотек Python[cite: 1].
