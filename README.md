# WikiCode — Справочник для начинающего программиста

WikiCode — это учебный веб-сайт, который представляет собой удобный справочник по основам программирования. Мы собрали в одном месте базовую теорию, шпаргалки и разбор основных тем, чтобы новичкам было проще учиться и быстро находить нужную информацию. 
# Для чего нужен сайт
Когда только начинаешь изучать программирование, легко запутаться в большом количестве информации из разных источников. 
Наш справочник помогает: 
Быстро вспомнить синтаксис и базовые конструкции кода. 
Повторить основные темы перед практикой или парами.
Изучать теорию в простом и понятном формате без лишней воды.
# Что делает сайт
Открывает список тем и разделов по программированию.
Показывает статьи, объяснения и примеры кода.
Позволяет быстро переключаться между нужными материалами.
# На чём сделан проект
Python — серверная часть (main.py). 
HTML и CSS — верстка страниц и внешний вид сайта (index.html, style.css).   
Скрипты и файлы данных — хранение и вывод статей на страницу.  
Как запустить
Установить библиотеки командой: pip install -r requirements.txt   
Запустить сервер командой: python main.py   
Открыть в браузере адрес: http://127.0.0.1:8000
